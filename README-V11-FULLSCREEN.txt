TRANSWISATA FLIGHT MANUALS V11 – FULLSCREEN PREVIEW

Perubahan dari V10:
- Tombol ⛶ Fullscreen / Exit Fullscreen pada toolbar Preview PDF.
- Tombol F pada keyboard saat preview terbuka (selain ketika mengetik di kotak input).
- Browser mendukung Fullscreen API: tampilan memenuhi layar, Escape kembali ke mode biasa.
- iPhone/Safari tertentu tidak mendukung Fullscreen API pada elemen PDF: otomatis menggunakan mode fokus, menyembunyikan informasi bawah dan merapatkan toolbar. Untuk layar lebih luas, instal PWA ke Home Screen.
- Preview, PDF Asli, Search, Make Offline, konfigurasi Firebase dan rules tidak diubah.

Instalasi: upload seluruh isi folder ke GitHub Pages, lalu buka ulang aplikasi online untuk pembaruan cache.
