TRANSWISATA FLIGHT MANUALS V15 — MOBILE FULLSCREEN

- Mempertahankan perubahan V14 (Smart Install).
- Fullscreen pada ponsel menjadi mode imersif: toolbar tersembunyi, PDF memanfaatkan seluruh lebar viewport.
- Kontrol ringkas: Keluar, Halaman, Zoom +/-, dan Menu untuk membuka toolbar lengkap.
- Tinggi viewer mengikuti visualViewport agar mengurangi area kosong akibat browser mobile.
- PDF.js untuk file yang sudah selesai dimuat mendukung fit-width dan pencarian.
- PDF native iframe pada iOS/Safari memiliki keterbatasan tampilan di luar kendali aplikasi. Jika belum tampil optimal, pilih PDF Asli atau Make Offline dan pastikan PDF.js berhasil dimuat.
- iPhone Safari tidak selalu mengizinkan fullscreen API; aplikasi memberi mode fokus. Untuk ruang layar maksimal gunakan Add to Home Screen.

Deploy: upload semua isi folder ke GitHub Pages; refresh saat online; jangan Clear Site Data karena manual offline bisa terhapus.
Penting: uji setiap perangkat dan revision current sebelum penerbangan.
